# Raspberry-Pi-NAS
The progress of my own ARM based NAS with everything I have downloaded in it.

Before all, I know using a raspberry for a stationary device like this is not the brightest idea, but I had it resting without a usecase for a long time in my room, and building a NAS out of it made the most sense.

Based on a 8gb Pi 5.

HARDWARE:
->Original 64 GB A1 sd Card for the OS
->Original 27 Watts Raspberry AC Power adapter
->1 x 1TB Seagate 2.5" Sata / ST1000LM049 / 6 Gb/s (Connected via 3.0 2.5" to USB 3.0 adapter)
->1 x 500 GB Hitachi 2.5" Sata / HTS545050B9A300 / 3 Gb/s (Connected via 3.0 2.5" to USB 3.0 adapter)
->An externally powered 4x USB 3 HUB

PHYSICAL NETWORK DESIGN:
Router -- CAT 5 cable -- Gigabit switch |
                                        |-- Raspberry Pi 5 NAS
                                        +-- Laptop
                                        +-- Other Devices

SOFTWARE:
-> 64 Bit Pi OS Lite (No GUI) (On the SD card)
